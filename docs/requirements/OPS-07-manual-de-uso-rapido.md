# OPS-07 - Manual de uso rápido

### OPS-07: Manual de uso rápido
**Prioridad:** M

**Descripción:**
El cliente pidió, además del manual completo, un manual de uso rápido para el día a día: una guía corta por rol con los pasos más comunes.

**Criterios de aceptación:**
- [ ] Una o dos páginas por rol (administrador, supervisor, técnico, cuenta de hospital).
- [ ] Entre 5 y 8 tareas frecuentes por rol, con pasos numerados y capturas pequeñas.
- [ ] Coherente con el manual completo (mismos nombres de pantallas y botones).
- [ ] Entregado en Word editable y PDF, con el logo de TodoGas.

**Implementación:**
Pendiente. Se redacta junto con el manual completo (OPS-06).
