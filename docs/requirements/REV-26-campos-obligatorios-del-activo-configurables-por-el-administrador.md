# REV-26 - Campos obligatorios del activo configurables por el administrador

### REV-26: Campos obligatorios del activo configurables por el administrador
**Prioridad:** C

**Descripción:**
Cada cliente exige datos distintos al registrar un equipo. El administrador debería elegir cuáles campos son obligatorios.

**Criterios de aceptación:**
- [ ] El administrador elige los campos obligatorios del activo
- [ ] El backend valida esa configuración
- [ ] El formulario web marca los obligatorios
- [ ] La importación respeta la configuración
- [ ] Existe un valor por defecto

**Implementación:**
Pendiente. Hoy los obligatorios están fijos en el serializador de activos.
